### 그래프
정점(node)과 간선(edge)로 이루어진 그래프를 연결시키는 알고리즘. 연결의 기준에 따라서 여러 구현 알고리즘이 있다.   

그래프 표현(데이터저장) 방법:   
**인접행렬(adjacency matrix)**: 2차원 배열에 연결정보를 저장. 구현은 간단하지만 공간이 많이 차지.
**인접 리스트(adjacency list)**: 각 노드마다 연결된 노드를 리스트로 관리. 메모리 효율이 좋음.

그래프 탐색 방법:   
**크루스칼**: 모든 간선의 가중치를 먼저 정렬하고, 가장 가중치가 작은 간선을 선택하여 루트 정점을 연결한다. Union-Find 구조를 사용하며 Find함수로 탐색한 루트 정점이 서로 다를 경우 Union 함수를 사용해 하나의 그래프로 만들고 이때 발생한 비용을 획득한다. Find함수는 재귀적으로 설계하여 부모 노드를 탐색해나가도록 설계한다. 정점개수-1 만큼 경로가 탐색되었다면 더이상 탐색을 하지 않고 종료하여 작업량을 최소화한다.   
**프림**: 간선을 선택할때 현재 정점에서 발생하는 가장 최소비용의 간선을 선택한다. heapq를 사용하고 (비용, 정점) 을 누적하며 그래프를 연결한다. 노드 수와 동일한 크기의 visited 리스트를 활용하여 해당 노드가 이미 방문되었는지 판단한다.    
**다익스트라**:한 정점에서 다음 정점으로 넘어가는 간선을 선택할때 전체 누적비용을 고려한다. heapq를 사용하고 (누적비용, 정점) 정보를 사용하여 그래프를 연결한다. 노드 수와 동일한 크기의 visited 리스트를 활용하여 해당 노드가 이미 방문되었는지 판단한다.   
**DFS,BFS***: 깊이 또는 너비 탐색방법.   

### 완전탐색
모든 케이스를 확인하면서 결과를 확인해야하는 케이스. 확인해야하는 케이스가 적은 경우에 사용해야한다.   

### 이분탐색
많은 처리량이 필요한 작업에서 계산해야하는 목표값이 발생할 수 있는 최대 범위 안에서 left-right의 중간값 mid가 원하는 목표값을 만족하는 지 탐색하여 연산량을 절반으로 줄이는 방법. 최소값들의 최대값, 또는 최대값들의 최소값 같은 결과를 탐색할 때 용이하다.   
mid값이 목표 T의 조건에 만족하지 않으면 left 또는 right를 mid+1, mid-1 로 이동시키면서 새로운 mid와 T를 비교한다.   

### 그리디(Greedy)
완전탐색과 비슷하게 케이스의 처음부터 정답을 만족하는지 확인하며 나아간다.
